# (AI)RCADE — Age & Expertise Question Bank


This file contains the question bank organised by **age group** and **AI expertise level**.

For each of the **15 combinations** (5 age groups × 3 expertise levels), there are **20 questions**.
In gameplay, **5 random questions** should be selected from the matching bank for a given session.

## Scoring Alignment

- **Option A** = high AI use, high environmental burden — default mapping: `weight: 1-2`, `moralScore: 0`
- **Option B** = moderate AI use, practical balance — default mapping: `weight: 3-4`, `moralScore: 1`
- **Option C** = low / targeted AI use, intentional choice — default mapping: `weight: 5-6`, `moralScore: 2`

The common question displayed on screen is: **How do you use AI?**  
Each scenario below completes that question.
